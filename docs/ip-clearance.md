# IP clearance — games, names and assets

Every game and every asset passes this before it ships (decisions.md 2026-10-26). It keeps us close
to safe; it is not legal advice. A one-hour review by an IP lawyer happens before the paid release,
with this file as the input.

## The rules

| What | Protected? | What we do |
|---|---|---|
| Rules and mechanics of a game | No: ideas and systems are not copyrightable (US 17 U.S.C. §102(b)) | Build any traditional game from its rules |
| Names | Sometimes trademarks | Our own or generic names; search before use |
| Look and feel: art, sounds, layout | Yes (Tetris v. Xio, 2012: a visual clone lost) | Our own art, sounds and layout; never imitate another app |
| Specific content: puzzles, texts, lists | Yes | Generated by our code or written by us |
| Code from other projects | Yes, and GPL in a paid app is a real risk | Never copied (AGENTS.md "Several agents at once" rule 4) |
| Clinical tests (MoCA, UFOV, test layouts) | Yes, and they read as a medical app | Never built (`research-2026-09.md` §3) |

Names we never use: Simon, Shanghai, Klotski, KenKen, Picross, Wordle, 24 Game, Lumosity or BrainHQ
game names. "Sudoku" is a Nikoli trademark in Japan only; check before a Japanese release.

## Third-party assets — what we checked on 2026-10-27

We keep this app free of third-party art, fonts, sounds, puzzles or code. On 2026-10-27 we verified the repo:

- **Fonts:** no bundled font files. `find MenteViva -name "*.ttf" -o -name "*.otf" -o -name "*.woff*"` returned nothing. All text uses system fonts via SwiftUI (`.font`, `.fontDesign(.rounded/.serif)`, Dynamic Type) — San Francisco on iOS, no custom font to license.
- **Images:** the only image in the bundle is `MenteViva/Assets.xcassets/AppIcon.appiconset/icon-1024.png`, generated by `tools/generate_icon.swift` and owned by the repo — no stock photos or icons. The asset catalog otherwise has only `Contents.json` and the `AppIcon` set.
- **Emoji as art:** game marks (`GameID.emoji`: 🧩 🎨 🐾 🔢 👀 📷 ✏️ 🃏 💬 🔁 🔷 🀄 🧱) are Apple Color Emoji system glyphs rendered by the OS, not image files. They need no licence beyond the OS.
- **Sounds:** `Services/SoundPlayer.swift` plays synthesized tones via AVFoundation — no `.mp3` / `.wav` files in the repo. `find MenteViva -name "*.mp3" -o -name "*.wav" -o -name "*.aiff" -o -name "*.m4a"` returned nothing.
- **Puzzles and texts:** Sudoku boards (`SudokuPuzzle.swift`), card deals (`UpOrDownDeal.swift`), sayings (`Sayings.swift`, `SayingsDeck.swift`), everyday objects (`EverydayObjects.swift`) and all other game content are generated by our code or written by us and stored in `Localizable.xcstrings` (EN + ES in the same commit).
- **Code:** no third-party dependency (conventions §1, AGENTS.md). `Package.swift` / package managers are not present; imports are SwiftUI / SwiftData / Foundation / AVFoundation only. No copied code per AGENTS.md "Several agents at once" rule 4.

If any third-party asset is ever added, list it here: file, source URL, licence, and date.

## AI-generated pictures

**Output rights:** OpenAI's [Terms of Use, Content → Ownership of content](https://openai.com/policies/terms-of-use/)
(effective 2026-01-01, checked 2026-10-27) state:

> We hereby assign to you all our right, title, and interest, if any, in and to Output.

This is the output-rights basis for using selected generated illustrations in
the distributed app, including commercial distribution, subject to the applicable
service/account terms and others' rights. It is not a promise of uniqueness,
copyright protection or non-infringement. Confirm the applicable account terms
in #226 before release rather than treating this quotation as legal sign-off.

**Copyright:** AI-generated expression may not itself be protectable; the owner
accepts that others could reuse it in an open-source project. Human-authored
contributions may have a different status. The [US Copyright Office's report announcement](https://www.copyright.gov/newsnet/2025/1060.html)
explains that prompts alone do not establish human authorship. Do not promise
exclusive rights in generated pixels.

**Every batch:** append a complete prompt/tool/date row per new slug to
`art-prompts.md`, record the selected files here, and check resemblance to
existing characters, distinctive accessories, poses, compositions and branding.
Use original designs; do not copy or trace a third-party example even where a
licence appears permissive. Log the actual provider/model/version when exposed,
or say it is unexposed. #226 must review this section and the final chosen assets.
