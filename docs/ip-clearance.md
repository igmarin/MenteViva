# IP clearance — games, names and assets

Every game and every asset passes this before it ships (decisions.md 2026-10-26). It keeps us close
to safe; it is not legal advice. A one-hour review by an IP lawyer happens before the paid release,
with this file as the input.

## The rules

| What | Protected? | What we do |
|---|---|---|
| Rules and mechanics of a game | No: ideas and systems are not copyrightable (US 17 U.S.C. §102(b)) | Build any traditional game from its rules |
| Names | Sometimes trademarks | Our own or generic names; search before use |
| Look and feel: art, sounds, layout | Yes (Tetris v. Xio, 2012: a visual clone lost) | Our own art, sounds and layout; never imitate another app |
| Specific content: puzzles, texts, lists | Yes | Generated by our code or written by us |
| Code from other projects | Yes, and GPL in a paid app is a real risk | Never copied (AGENTS.md "Several agents at once" rule 4) |
| Clinical tests (MoCA, UFOV, test layouts) | Yes, and they read as a medical app | Never built (`research-2026-09.md` §3) |

Names we never use: Simon, Shanghai, Klotski, KenKen, Picross, Wordle, 24 Game, Lumosity or BrainHQ
game names. "Sudoku" is a Nikoli trademark in Japan only; check before a Japanese release.
