Static code audit against `docs/conventions.md` §4 and `AGENTS.md`
accessibility floor: ≥100pt touch targets on game interactions (60pt min for
list rows), VoiceOver labels/traits on every interactive element, Dynamic Type
resilience, no color-only information, reduced-motion handling, contrast.

Scope: HomeView, HistoryView, all 5 games (Memory Lane, Color Clash,
Name the Herd, Number Trail, Quick Eyes), CelebrationView.
Method: full source read of every interactive element, color cue, font and
animation. Device-dependent items are listed as **needs-human**, not verified.

## Human checklist (device required)

1. **VoiceOver walkthrough** — every screen, ES then EN: Home → each game →
   full round → Celebration → History. Check focus order, hint narration
   ("Card N of 16", "Pair found", "Already picked", shape hints), and that
   disabled matched cards read acceptably.
2. **Emoji label quality** — confirm VoiceOver reads 🌻🐢🍎🎸🌙☕️🦋🍊 etc.
   clearly for an older ES voice; if not, add explicit localized labels.
3. **Dynamic Type** — run all screens at AX1, AX3, AX5; confirm no clipping
   (watch: ColorClash 64pt word, 2-line game names
   in History rows).
4. **Color-blind sanity** — play Color Clash and Name the Herd with a
   color-vision-deficiency filter: shapes/checkmarks must carry the answer.
5. **Quick Eyes + VoiceOver product decision** — the timed flash is
   visual-only today; decide between a VoiceOver mode or explicitly
   scoping the game as visual.
6. **Dark Mode eyeball** — soft `.opacity` tints and confetti contrast.
