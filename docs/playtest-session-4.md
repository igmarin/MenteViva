# Session sheet — playtest #4 (dad, one week on TestFlight)

Print this. Part A is for him: one page, large type, no marks. Parts B–E stay
with you; never hand them to him. Their prompts ("test", "grade", "exit test")
are for you, never read aloud as written: ask "How was that one?" instead. Method and the one rule ("watch, don't help") live in
[playtest.md](playtest.md). Issue: #231. This one runs **unsupervised for seven
days**: he plays on his own, you ask three easy questions each evening and fill
the log. It checks four things:

1. Does the level staircase (#191) climb too fast, or too slow, for him?
2. Can he get through onboarding (#192) alone?
3. Which of the four new games (#193) does he come back to: Repeat the Sequence,
   Tangram, Tile Pairs, Sliding Blocks?
4. Does Tangram work with his hands (tap, drag, turn, flip)?

Ready to run the day the first TestFlight build (#229) is live on his iPad. Until
then there is nothing to install, so this sheet stays on the shelf.

## Before the week starts

1. **Install over the old build, never delete it.** Deleting erases his week and
   progress. TestFlight builds don't carry the 7-day expiry of free-account installs. Install the TestFlight build over his current one and check, before day 1, that his week is still there.
2. **The exception: onboarding.** It shows on first launch only (#192). To see him
   do it alone, he needs a build that has never opened on his iPad. If his iPad
   already has the app: Settings → My plan holds the same four questions; use
   that, and write "My plan, not first run" in the header. Do not delete a build
   in the middle of his week.
3. **Open each new game yourself once, first.** His iPad is on iOS 17.7 and there
   is no iOS 17 simulator. A freeze, a blank screen or a board that doesn't fit is
   a bug to fix before day 1, not a finding.
4. **Leave Set up alone.** No hidden games, no pinned level: a pinned level turns
   the staircase off (how-it-works.md, Levels), and the staircase is the point.
5. **Write down his starting levels.** Settings → My progress, per game. You need
   them to judge "too fast".
6. Volume at his level. Hand him the iPad on the Home screen. Say only: "Use it
   whenever you like this week. I'll ask how it went each evening." Nothing else.

## Where each finding goes

| Observation | Feeds |
|---|---|
| Froze, blank screen or a layout that does not fit on iOS 17.7 | fix first; there is no iOS 17 simulator, so reproduce on the iPad |
| Asked for help in onboarding, or stopped at one question | a new `design` issue for that step; small copy fixes the same day (onboarding epic #192) |
| Levels climbed 3+ steps in a week, or he said "too hard" twice | tell me: the staircase thresholds (`DailyPolicy` thresholds, #198), how-it-works.md; pinning a level is the family-side workaround, not the fix |
| Levels never moved, or he said "too easy" for three days | same: thresholds, or the next-level offer not showing (#207) |
| A level-change line he didn't understand, or that felt like a grade | the line's wording (`level.explain.*`) in `Localizable.xcstrings`, EN + ES, warm copy only |
| He took "Keep it as it is" every time, or "Yes" then went back | the offer's wording and timing (#207) |
| Tangram: drag slips, pieces covered by his finger, tap-only works better | make tap the one path, or enlarge pieces: a new issue on #219 |
| A new game he called homework, or any "test" word | Jev judgment first (AGENTS.md Workflow 3), then decisions.md; the owner decides |
| A new game he asked for again | keep it in the first release; note in roadmap |
| A game he never opened | check Home dealt it; if dealt and ignored, that game's picture or name needs work |
| Sequence, Tile Pairs or Sliding Blocks misread (symbols, small tiles) | tile size and contrast on that game; touch-target floor is 60pt, aim 100pt (conventions §4) |
| He opened the app on his own twice or more | roadmap exit criteria (mvp.md G1b) |
| He still said "same as yesterday" | variety is not solved: ask what he wants more of, then score the next idea with Jev before building |
